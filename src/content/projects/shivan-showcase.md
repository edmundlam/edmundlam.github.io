Shivan Showcase is a full-stack voting platform where users compare and rank Magic: The Gathering card artwork using an
ELO-based rating system. Built with Vue 3 and FastAPI and deployed on Render and Supabase, the application features
side-by-side voting, real-time ELO score calculations, and multiple leaderboards for artworks, artists, and sets.

- [Live site](https://www.shivanshowcase.com/)
