Shivan Showcase is a full-stack voting platform where users compare and rank Magic: The Gathering card artwork using an
ELO-based rating system. Built with Vue 3 and FastAPI, the application features side-by-side voting, real-time ELO score
calculations, and multiple leaderboards for artworks, artists, and sets. The architecture uses a repository pattern with
service layers, PostgreSQL with SQLModel ORM, and a URL-first approach for shareable filtered views.
